Toad — a mark that idles

Six short beats instead of one loop. Each starts and ends at rest, so they can be butted together in any order — the scheduler waits a random gap, picks a beat weighted by what the agent is actually doing, and never plays the same one twice running. The result reads as something alive rather than something buffering, and it never lands on the same rhythm twice.
